PCでの使い方

  1. ブックマークバーを表示します（Chrome / Edge は Ctrl+Shift+B、Mac は ⌘+Shift+B）。
  2. 下の「SB Multi」ボタンをブックマークバーへドラッグして登録します（クリックでは登録されません）。
  3. SpankBangで検索し、検索結果ページで登録したブックマークをクリックします。
  4. サムネイル左上のチェックで動画を最大16本選び、右下の「Multi Playerで開く」を押すと、新しいタブでプレーヤーが開きます。
  5. 別の検索ページに移ったら、もう一度ブックマークをクリックすると選択の続きができます。動画ページでは「この動画を追加」も使えます。
SB Multi

スマホでの使い方

  1. 下の「コードをコピー」を押します。
  2. このページをブックマークに追加し、そのブックマークを編集します。名前を「SB Multi」に、URLをコピーしたコードに置き換えて保存します。
  3. SpankBangで検索し、検索結果ページでブックマークを実行します。
    • Android（Chrome）: アドレスバーに「SB Multi」と入力し、候補に出たブックマークをタップします。
    • iPhone（Safari）: ブックマーク一覧を開き、「SB Multi」をタップします。
  4. サムネイル左上のチェックで動画を選び、「Multi Playerで開く」を押します。
